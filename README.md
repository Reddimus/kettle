# Kettle 5.9.0 vs 6.0.0: release comparison media

Visual comparison media for Kettle 6.0.0 (PR #823). Each figure pairs the same scripted task captured from Kettle 5.9.0 (`e58e367b9`) and Kettle 6.0.0 (`4c4aa880c` on Linux, `9d1e754e9` on macOS) in an isolated desktop session, with differences annotated. `*-old.png` and `*-new.png` are the unmarked originals, and `claims.json` records the measurements behind each figure.

`linux/videos/` contains side-by-side 30 fps compositor recordings (5.9.0 on the left, 6.0.0 on the right) captured in an isolated GNOME 50 session on Ubuntu 26.04, along with a GIF preview for each MP4.
