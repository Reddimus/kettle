# Kettle 5.9.0 vs 6.0.0: release comparison media

Media for the 6.0.0 release review (PR #823). Each figure pairs one scripted step captured from the public Kettle 5.9.0 build and from the 6.0.0 candidate by the same harness, in the same private session, then marks what changed. `*-old.png` and `*-new.png` are the unmarked originals. `claims.json` lists every figure with its measured basis.
