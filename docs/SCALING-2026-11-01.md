# Scaling diagnostics, 2026-11-01

These measurements are **inconclusive for architecture changes**. The macOS
standing preflight refused this host because existing terminal sessions, an
active client and load prevented an idle calibration. Those owner processes
were preserved. These observations are neither a published standing nor a
performance non-regression gate. No Unix reader consolidation, shared mutable
font system or search-worker rewrite resulted.

## Candidate and method

Host: Apple M5 Max, 48 GiB, macOS 27.2. The frozen terminal SHA-256 was
`803f1be708bfb406479d85314702409f1f94ff04ad9da2bc46f45087f3494d8a`,
with its separately built matching media worker. Rust inputs match the keyboard
mode candidate `cc3675a8`; subsequent qualification changes affect verification
scripts and documentation. Two equal-depth copies of the same executable
formed A/A controls, alternating AB/BA order over three pairs per complete
state. Artifact and helper hashes and fixture cleanup were checked.

PTY states use one window and one PTY per tab, with one tab visible. They do
not simulate 64 simultaneously visible split panes. Window states use one PTY
per native window and check the observed native-window count. Children enter
raw mode and execute `cat`; their tracking wrappers and child RSS are outside
the terminal counters. Blink, recording, session restore and update checks are
disabled. Each non-history sample settles for 20 seconds before a 30-second
idle interval. CPU is a percentage of one core. RSS, physical footprint and
lifetime maximum footprint come from native process counters; a window's
increment includes renderer, GPU and PTY state, not just font allocations.

The per-process descriptor soft limit was 1024, within the existing hard
limit. The original 256-limit attempt reached descriptor exhaustion at 64
PTYs and is retained separately. No system or owner limit was changed. Under
1024, one later 64-PTY admission timed out without an explained cause after
three successful measured launches. Six subsequent admission-only controls
passed; they do not erase that timeout or complete the interrupted campaign.

## History and query observations

Each history state has six launches with exactly the requested number of
retained rows, a disabled byte cap, and short lines containing row numbers,
rare needles and Japanese text. The normal byte budget remains enabled in
production; this fixture deliberately removes it to hold row count constant.
The control API dispatches queries and observes search state and nonempty
match rectangles. Positive-query timing ends at the first visible match,
not completion of every retained-history search slice. The absent query ends
at `No match`. Input timing sends ten raw PTY markers after leaving search and
observes the grid; it does not measure native typing or concurrent search.

| 1,000 | 543.2 | 83.4 | 550.2 | 83.4 | 33.3 |
| 10,000 | 594.0 | 83.4 | 1,083.3 | 83.7 | 33.3 |
| 100,000 | 589.3 | 83.9 | 6,950.5 | 83.5 | 33.3 |

History memory snapshots were taken during startup and may include transient
font preload allocations. They are not comparable to the settled idle memory
in the preceding table. All 36 launches in the window/history segment closed
all owned fixtures. Earlier failed attempts remain part of the evidence.

A separate six-launch A/A diagnostic at 100,000 rows first observed an active
`Searching` state, then cancelled it. Search closed in 5.1-5.9 ms; subsequent
PTY input became visible in 0.9-17.0 ms. A second pending absent query was
replaced with a matching query, which produced visible match rectangles in
11.6-16.2 ms. Those matches remained after eight seconds, beyond the old
absent-query duration. All six fixtures closed. Two private probe setup
failures (an artifact-path collision and an assertion missing the status
label's ellipsis) are retained and were corrected before these six controls.

This distinguishes the long traversal duration from an observed event-loop
stall under these fixture conditions. The signals still are not native
key-to-pixel latency or a calibrated non-regression result. The current
architecture remains deferred pending calibrated evidence; these diagnostics
do not establish that a worker or sharing change would be beneficial or
unnecessary.
