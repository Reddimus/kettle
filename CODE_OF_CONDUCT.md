# Code of Conduct

The kettle project adopts the **Contributor Covenant, version 2.1** as
its code of conduct. Read the full canonical text at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

The text covers:

- Our pledge to make participation a harassment-free experience for
  everyone, regardless of background or identity.
- Standards of behavior we expect from contributors.
- Enforcement responsibilities and the scope where the code applies.
- How to report a concern and what happens after a report.
- The enforcement guidelines maintainers follow when responding.

## Reporting

If you witness or experience behavior that violates this code, please
report it privately to the project maintainers via GitHub's private
vulnerability-reporting form
(<https://github.com/Reddimus/kettle/security/advisories/new>) — the
same channel `SECURITY.md` uses for confidential reports. We will
review every report, keep the reporter's identity confidential, and
respond within the timelines the canonical text sets out.

For security-sensitive reports specifically, please follow
[`SECURITY.md`](SECURITY.md) instead.

## Why we adopt by reference

The Contributor Covenant is maintained at version 2.1 by an active
foundation; pinning to the canonical URL means a future revision is
one bump (`/version/2/1/` → `/version/2/2/`) rather than a copy-paste
diff. Projects that link rather than copy include the Rust language,
Kubernetes, and many others.
