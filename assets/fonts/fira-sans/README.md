# Fira Sans diagram faces

Unmodified Fira Sans 4.301 regular, bold, italic and bold italic outlines from
https://github.com/bBoxType/FiraSans at revision
`f54eeb3124c63fe9b5bcd36d09d1cd46788cd15e`.

Files come from `Fira_Sans_4_3/Fonts/Fira_Sans_TTF_4301/Normal/`, with Roman and
Italic style subdirectories. Their original copyright and OFL 1.1 license are
preserved in the font name tables and OFL.txt. The reserved font name is Fira.

These matching faces keep diagram measurement and SVG output on the same
weight and style. They are embedded only in the macOS and Linux media worker,
with no host font discovery. Explicit per-job fallback fonts supplement them.
